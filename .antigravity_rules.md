# Antigravity Developer Guidelines

This file serves as the "Source of Truth" for the Antigravity AI agent. You MUST review this file before creating any implementation plans or making code changes in this repository.

## Project Overview
- **Framework**: Django 6.0.4
- **API Framework**: Django Rest Framework (DRF)
- **Primary App**: `core`
- **Database**: SQLite (default)

## Core Principles
1. **DRF First**: All API endpoints should be built using Django Rest Framework.
2. **Clean Architecture**:
   - Models in `models.py`.
   - Serializers in `serializers.py` (create if not exists).
   - Views in `views.py` (Class-based views preferred).
   - URLs in `urls.py` (app-level).
3. **Naming Conventions**:
   - Follow PEP 8 for Python code.
   - Use descriptive, snake_case for variables and functions.
   - Use PascalCase for Classes.
4. **Migrations**: Always generate and check migrations (`makemigrations`) after model changes.
5. **No Placeholders**: Do not leave TODOs or placeholders in the code unless explicitly asked.

## Tooling & Environment
- **Package Manager**: `pip` (Python) / `pnpm` (JavaScript/Node if applicable).
- **Environment**: Always use the `.venv` virtual environment for running commands.
- **Commands**: 
  - Use `python manage.py <command>` for Django tasks.
  - Prefix with `.\.venv\Scripts\python.exe` if needed for environment consistency.

## Implementation Workflow
1. **Research**: 
   - Review official documentation: [Django 6.0](https://docs.djangoproject.com/en/6.0/) and [Django Rest Framework](https://www.django-rest-framework.org/).
   - Understand existing patterns in `core` and `vibecode_prep`.
2. **Plan**: Create an `implementation_plan.md` in the artifacts directory.
3. **Execute**: Follow the approved plan, updating `task.md`.
4. **Verify**: Ensure the dev server runs and migrations are applied.
5. **Document**: Update `PROJECT_STEPS.md` with the major steps taken (omitting bug fixes).
